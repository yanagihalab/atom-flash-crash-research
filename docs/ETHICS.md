# 倫理上の注意とアドレス帰属

本リポジトリには公開ブロックチェーンのアドレスと取引ハッシュが含まれます。これらは
研究結果の再現に必要な公開識別子ですが、自然人の氏名、取引所内部口座又は実質的所有者
を示すものではありません。

## ラベルの意味

- `metadata/exchange_address_labels.json`のラベルは、公開資料に記載されたアドレスとの
  完全一致に基づくサービス関連ラベルです。
- ラベルは個々の送信者、入金者、売り注文者又は受益者を識別しません。
- 行動パターンから抽出した未確認候補は感度分析だけに用い、確認済み取引所アドレスと
  同一視しません。
- 大口送金だけを理由とする候補は取引所フロー定義から除外しています。

## 禁止される解釈

このデータだけを根拠として、特定アドレス又は人物を「攻撃者」「相場操縦者」「売り手」
と表示しないでください。オンチェーン確定時刻は取引所内部残高への反映時刻でも、注文
発生時刻でもありません。

## 研究上の限界

公開データにはBinanceの口座・副口座ID、taker order ID、client order ID、APIキー・IP
監査記録、清算フラグ、入金反映時刻及び履歴板がありません。したがって、時間的近接は
関連候補を示しても、因果関係や主体帰属を立証しません。
